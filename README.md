# 🍕 React Props Practice

A simple React project built to understand how **props work in React** by passing pizza details, such as an image, title, and price, from a parent component to a reusable child component.

## 📌 About the Project

This project demonstrates how to create reusable components in React using props. The pizza card displays an image, pizza name, and price received from the parent component.

## ✨ Features

- Reusable React child component
- Passing data using props
- Displaying dynamic pizza images
- Showing pizza names and prices
- Custom styling using CSS
- Practicing component-based UI development

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd props-practice
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
